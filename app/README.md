# Hordex mobile app (Android, Capacitor)

The **cockpit**: drive the swarm from your phone, watch it work live, read the
report, and unlock Pro via RevenueCat. The heavy lifting (the actual bots) runs
on your deployed backend — see `../DEPLOY.md`.

This is the artifact you submit for **Next Gen** (a real Android app; no store
listing required — just the video + this open-source repo).

## Prerequisites

- Node 18+
- **Android Studio** (for the SDK + an emulator or a connected device)
- A deployed backend URL (`../DEPLOY.md`) and a RevenueCat Test Store key
  (`../paywall/revenuecat-setup.md`)

## First-time setup

```bash
cd app
npm install
# Fill in app/www/config.js first (BACKEND_URL + REVENUECAT_API_KEY), then:
npx cap add android          # creates the native android/ project (gitignored)
npx cap sync android         # copies www/ + installs the RevenueCat plugin
npx cap open android         # opens Android Studio
```

In Android Studio, pick a device/emulator and press **Run**. To install on your
own phone for free (no paid account, no Play listing): enable **Developer
options → USB debugging**, plug in, and Run — or **Build → Build APK** and
sideload the APK.

Rebuild after web changes:

```bash
npx cap sync android         # after editing anything in www/
```

## Using it

1. First launch → tap **⚙ Settings** → paste your **backend URL** → Save.
2. Enter a target URL you own (or leave it and scan your own dev server), tick
   **"I own this"**, and **Release the swarm**.
3. Watch bots, coverage, and findings stream in live.
4. Tap **Unlock Pro** to run the RevenueCat purchase (Test Store sandbox) →
   the swarm cap jumps to 20 and the full security sweep + export unlock.

## What's here

```
app/
  capacitor.config.json   appId com.hordex.app, webDir www
  package.json            Capacitor + @revenuecat/purchases-capacitor
  www/
    index.html            the mobile cockpit UI
    config.js             backend URL + RevenueCat key (fill these in)
    revenuecat.js         RevenueCat purchase + entitlement gating (+ web mock)
  android/                generated by `cap add android` (gitignored)
```

> The native `android/` folder is generated locally and not committed — anyone
> cloning the repo regenerates it with `npx cap add android`.
